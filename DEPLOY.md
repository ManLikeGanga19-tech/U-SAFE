# Deployment

U-SAFE's backend runs on a **self-hosted VPS** (Docker Compose), and the storefront +
admin run on **Vercel**. The old Render setup has been retired.

➡️ See **[DEPLOY-VPS.md](DEPLOY-VPS.md)** for the full, current deployment guide:
topology, first-time provisioning, edge wiring on the shared VPS, the self-healing
Caddy guard, routine deploys (GitHub Actions → VPS), Vercel env vars, and M-Pesa.
